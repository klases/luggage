# Workflows

A workflow determines intake and delivery. Select depth separately. Compact is the default. Use selective specialists for distinct risk areas or a challenger for consequential or disputed evidence when authorized. State what actually ran.

| Workflow | Intake and delivery |
|---|---|
| Interactive | For a bare invocation, ask what to review and which focus matters. Reuse answers already given. State the comparison and ask only about missing decisions that affect scope or evidence. Report in the conversation and support follow-up on specific traces. |
| Private PR report | Pin the authorized PR base and head, task context and trusted policy. Resolve stale revision and missing context before claiming completion. Return in the conversation or write to an explicitly authorized private destination. Include revision, findings, coverage, candidate dispositions and verification limits. |
| Coding-agent handoff | Accept the task and frozen implementation from the coordinator. Review the evidence before reading the builder's conclusions when possible. Send back actionable defects, unresolved owner decisions, and the checks needed on a follow-up revision. Keep review separate from edits. |

For unattended work, return an incomplete report listing missing required scope, authorization or inputs. If optional evidence is unavailable, continue with the permitted evidence and name the gap. Treat publication and execution as separate authorizations.
